# Balanced 10/10 question type split per Round

Each Round contains exactly 10 Name Questions and 10 Position Questions, shuffled randomly, rather than a purely random type assignment per question. A random split could produce heavily skewed Rounds (e.g. 18 Position / 2 Name), which would undermine the goal of drilling both skills equally in every session. A user-selectable mode was considered but deferred to v2 to keep the initial UI simple.
